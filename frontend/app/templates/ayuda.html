📚 Documentación del Sistema

Descripción

Sistema de facturación de recursos de infraestructura en la nube. Permite gestionar recursos, categorías, configuraciones, clientes e instancias.

Funcionalidades

  • Cargar Configuración: Importa recursos, categorías y clientes desde XML
  • Registrar Consumos: Carga los tiempos de uso de instancias
  • Consultar Datos: Visualiza información del sistema
  • Crear Datos: Añade elementos manualmente
  • Facturación: Genera facturas y descarga PDFs
  • Inicializar: Reinicia la base de datos

Tecnologías

  • Backend: Flask (Python) - API REST
  • Frontend: Django (Python) - Web App
  • Base de Datos: XML
  • PDFs: ReportLab

Formatos

  • Fechas: dd/mm/yyyy (ej: 15/10/2025)
  • Fecha-Hora: dd/mm/yyyy hh:mm (ej: 15/10/2025 14:30)
  • NIT: números-dígito (ej: 12345678-9 o 110339001-K)
  • Tipos de Recurso: Hardware o Software
  • Estados: Vigente o Cancelada

Flujo de Trabajo

  1. Cargar XML de configuración
  2. Verificar datos en Consultar
  3. Cargar XML de consumos
  4. Generar facturas por período
  5. Descargar PDFs
